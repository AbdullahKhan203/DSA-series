## 🔹 2. Concept of a Linked List

* A **linked list** is a *collection of nodes*, where **each node points to the next node**.

* Each **node** contains **two things**:

  1. **`value`** – the data stored in that node
  2. **`next`** – a *reference (address)* pointing to the next node in the list

* This connection continues **node → node → node**, until the **last node**,
  whose `next` becomes **`null`**, meaning the list ends there.

* Hence, the structure looks like:

  ```
  [value | next] → [value | next] → [value | next] → null
  ```

---

## 🔹 3. Head and Tail

* **Head** → the first node in the list

* **Tail** → the last node in the list

* When the list is **empty**, both `head` and `tail` are **`null`** (or sometimes same temporary node).

* When the list has **one node**, both `head` and `tail` point to the **same node**.

---

## 🔹 4. Node Internals

* Each node has a structure like this:

  ```js
  {
    value: 10,
    next: null
  }
  ```
* If another node exists, the first node’s `next` will point to it:

  ```js
  {
    value: 10,
    next: {
      value: 20,
      next: null
    }
  }
  ```
* This chain of references forms the entire linked list.

---

## 🔹 5. Linked List as Objects in JavaScript

* In JavaScript, we can represent each node as a **plain object**.

  ```js
  let node1 = {
    value: 100,
    next: null
  };
  ```

* If you add another node:

  ```js
  let node2 = {
    value: 200,
    next: null
  };

  node1.next = node2;
  ```

* Now the list looks like:

  ```
  node1 (100) → node2 (200) → null
  ```

---

## 🔹 6. The Role of Head and Tail Variables

* When we create the linked list initially, both `head` and `tail` refer to the same node.

  ```js
  let head = { value: 100, next: null };
  let tail = head;
  ```

* When we insert more nodes:

  * We set `tail.next = newNode`
  * Then update `tail = newNode`

  This ensures `tail` always points to the last node.

---

## 🔹 7. Important Concept — References in JavaScript

* **Objects in JavaScript are stored by reference**.
  That means if you assign one object to another variable, both point to the **same memory location**.

  ```js
  let a = { name: "Peter" };
  let b = a;
  b.name = "John";

  console.log(a.name); // prints "John"
  ```

* Both `a` and `b` refer to the *same* object in memory.

* This is important for linked lists:
  if you modify `tail.next`, it also changes the chain that `head` can see, because both reference the same structure.

## 🔹 8. Creating a LinkedList Class

* The instructor then defines a **class** to manage all linked list operations.

  ```js
  class LinkedList {
    constructor() {
      this.head = null;
      this.tail = null;
      this.size = 0; // optional, to track number of nodes
    }
  }
  ```

* Here:

  * `head` → first node
  * `tail` → last node
  * `size` → count of total nodes in the list

---

## 🔹 9. Inserting (Appending) a Node

* To add a node to the end of the list, define a function inside the class:

  ```js
  append(value) {
    const newNode = { value: value, next: null };

    if (this.head === null) {
      // List is empty
      this.head = newNode;
      this.tail = newNode;
    } else {
      // List already has nodes
      this.tail.next = newNode;  // link last node to new node
      this.tail = newNode;       // update tail
    }

    this.size++; // increase length count
  }
  ```

* Key idea:

  * When list is empty → first node becomes both head and tail.
  * Otherwise, attach the new node to the existing tail and move the tail pointer.

## 🔹 11. Why Head Changes When Tail Changes (Reference Concept)

* Because of *object references*, both head and tail point into the **same linked structure**.
* When you change something at the tail (like `tail.next`), that modification affects the entire structure because `head` refers to the same underlying memory.
* This is normal behavior in linked lists — not a bug.

---

## 🔹 12. Size Property

* A `size` counter is optional but useful:

  * Start `this.size = 0`
  * Each time you insert a node, `this.size++`
  * Later, you can easily print or return total length.

  ```js
  getSize() {
    return this.size;
  }
  ```

## ✅ Example Complete Code (summarized)

```js
class LinkedList {
  constructor() {
    this.head = null;
    this.tail = null;
    this.size = 0;
  }

  append(value) {
    const newNode = { value, next: null };

    if (!this.head) {
      this.head = newNode;
      this.tail = newNode;
    } else {
      this.tail.next = newNode;
      this.tail = newNode;
    }

    this.size++;
  }

  print() {
    let current = this.head;
    while (current) {
      console.log(current.value);
      current = current.next;
    }
  }
}

// Example usage:
const list = new LinkedList();
list.append(200);
list.append(300);
list.append(500);

list.print(); // 200 300 500
console.log("Size:", list.size);
```
